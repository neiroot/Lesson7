# AI-анализатор видеовстреч

Этот файл — краткая инструкция для проверки архива. Подробности, команды
тестов и результаты прогонов есть в `README.md`.

## Запуск на macOS Apple Silicon

Для подготовки нужны Python 3.12, Node.js 24, FFmpeg и FFprobe, Ollama, интернет и примерно 15 ГБ свободного места. Приложение запускалось на MacBook Air M1 с 8 ГБ памяти.

1. Установите [Homebrew](https://brew.sh/) и [Ollama](https://ollama.com/download). В первом окне Терминала запустите Ollama:

   ```bash
   OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 \
     OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 ollama serve
   ```

2. Распакуйте архив и в Терминале перейдите в папку `ai-meeting-analyzer`. Установите инструменты и создайте Python-окружение:

   ```bash
   brew install python@3.12 node@24 ffmpeg git-lfs
   export PATH="$(brew --prefix node@24)/bin:$PATH"
   python3.12 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r backend/requirements.lock
   npm --prefix frontend ci
   npm --prefix frontend run build
   cp -n .env.example .env
   ollama pull qwen3.5:2b --runner llamacpp
   ```

3. Примите условия доступа к [pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) в своём аккаунте Hugging Face. Создайте токен чтения. В том же окне Терминала подготовьте локальные модели. Введите токен в приглашение, он не будет отображён:

   ```zsh
   read -rs 'meeting_token?Токен Hugging Face: '
   printf '\n'
   HF_TOKEN="$meeting_token" python scripts/setup_models.py --check
   HF_TOKEN="$meeting_token" python scripts/setup_models.py
   unset meeting_token
   python scripts/check_models.py --offline
   ```

4. Запустите приложение из корня распакованного проекта:

   ```bash
   bash scripts/start.sh
   ```

   Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000), загрузите файл WebM или MP4 и
   дождитесь статуса «Готово». Расшифровка и конспект открываются из списка
   встреч. Результат сохраняется после обновления страницы. Чтобы остановить
   приложение, нажмите `Ctrl+C` в окне с сервером. При следующем запуске достаточно
   снова запустить Ollama, активировать `.venv` и выполнить `bash scripts/start.sh`.

Токен Hugging Face нужен только для первоначальной загрузки закрытых весов Community-1. Не вставляйте токен или API-ключи в исходники, `.env` и материалы сдачи. Скрипт удаляет HF-токены из окружения дочерних процессов. После загрузки моделей распознавание и конспектирование выполняются локально.

## Модели и инструменты

- **pyannote Community-1** определяет, где говорят разные участники, и формирует временные интервалы речи. Код не запускает её с Hugging Face-токеном.
- **WeSpeaker ResNet34** извлекает локальные голосовые признаки для сопоставления речи с профилями сотрудников. Автоматические имена требуют отдельной калибровки на размеченных записях. До неё спикеров подтверждают вручную.
- **Qwen3-ASR 0.6B, 8-bit, MLX** преобразует речь в текст. ASR-модель и среда для неё устанавливаются отдельно.
- **Qwen3.5 2B через Ollama** составляет русскоязычный конспект из расшифровки: краткое содержание, решения, задачи и открытые вопросы. Для генерации передаются структурированный формат и ссылки на реплики.
- **FFmpeg/FFprobe** проверяют и извлекают аудио из MP4 и WebM. **FastAPI**, **React/TypeScript** и **SQLite** обслуживают локальный интерфейс и сохраняют результаты между запусками.

Модели и ревизии закреплены в `scripts/models.lock.json`. После первоначальной загрузки приложение работает без интернета. Дополнительные подробности, команды тестов и фактические результаты запусков приведены в `README.md`.
